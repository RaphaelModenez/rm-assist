RM Assist - Acabamento Agenda e Histórico

Agenda:
- mostra quantidade de atendimentos hoje
- mostra quantidade de atrasados
- identifica claramente itens atrasados
- botão informa quantos atrasados existem
- mantém abertura direta da OS quando já iniciada

Histórico:
- filtro por todo o histórico, este mês ou este ano
- busca por cliente, OS, serviço e equipamento
- mostra quantidade de OS no filtro
- mostra total de valores de serviço do período filtrado

Envio:
1. Extraia o ZIP.
2. Envie a pasta app ao GitHub mantendo a estrutura.
3. Substitua:
   - app/agenda/page.tsx
   - app/historico/page.tsx
4. Faça Commit changes e aguarde GitHub Actions/Vercel.
