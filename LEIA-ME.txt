RM Assist - Múltiplos equipamentos | Etapa 3

O banco já foi atualizado automaticamente para permitir dados vinculados a cada equipamento.

Este patch:
- cria a tela /os/[id]/equipamentos para OS com vários equipamentos
- mostra um botão para cada equipamento da OS
- salva diagnóstico, serviço executado, recomendações, situação final e pendências por equipamento
- salva checklist por equipamento
- salva medições por equipamento
- salva fotos e legendas por equipamento
- mantém a conclusão/financeiro geral na OS existente
- modifica Serviços para abrir automaticamente a nova tela quando a OS tiver mais de um equipamento
- modifica o relatório para gerar um único documento com uma seção para cada equipamento

Arquivos:
app/os/[id]/equipamentos/page.tsx
app/os/[id]/relatorio/page.tsx
app/servicos/page.tsx

Após o commit:
1. Abra uma OS com 2+ equipamentos.
2. Preencha dados em dois equipamentos diferentes.
3. Vá para Conclusão da OS.
4. Finalize a OS.
5. Abra o relatório e confirme as seções separadas por equipamento.
